# For grant applicants: Multilingual AI Grant Application Assistant

An AI-powered grant application system that helps small businesses create complete applications from **voice input, business documents, and photos**. It supports **English, Amharic, and Afaan Oromo**, using speech-to-text, OCR, computer vision, translation, and LLMs to extract and structure information into **validated, editable applications** that can also be automatically evaluated and ranked.
